# Funngro Website Revamp

## Files
- `index.html` — Company page
- `teen.html` — Teen page
- `style.css` — responsive design system
- `SEO_AUDIT_REPORT.md` — SEO audit report
- `robots.txt` — crawl directive template
- `sitemap.xml` — sitemap template

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Deploy free
Upload the folder to GitHub and enable GitHub Pages, or drag the folder into a static hosting service such as Netlify/Vercel.

## Important
Before submission, replace the example domain in `robots.txt` and `sitemap.xml` with your actual deployed URL.
